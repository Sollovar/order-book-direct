# AsterDex

A crypto perpetuals exchange UI built with TanStack Start, React 19, TypeScript, and Tailwind CSS v4.

## How to run

```sh
bun install
bun run dev
```

The dev server runs on port 5000.

## Stack

- **Framework**: TanStack Start (SSR React)
- **Router**: TanStack Router (file-based routes)
- **Styling**: Tailwind CSS v4 + Radix UI + shadcn/ui components
- **Build**: Vite 8 via `@lovable.dev/vite-tanstack-config`
- **Runtime**: Bun

## Routes

- `/` — Landing page
- `/trade` — Trading interface (order book, pair selector)
